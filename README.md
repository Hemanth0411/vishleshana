# Vishleshana — The Code Lens

> *Vishleshana (विश्लेषण): analysis, in Sanskrit.*

**Graph-aware Python codebase understanding system.**

CodeLens ingests a Python repository (GitHub URL or local path), extracts its structure using static analysis, builds a dependency and call graph, computes complexity metrics, and presents everything through a local Streamlit UI. A natural language query interface lets developers ask questions about the codebase — answers are grounded in the extracted graph and generated by NVIDIA NIM.

---

## Features

- 📥 **Ingest** any Python repo via GitHub URL or local path
- 🌳 **AST-based extraction** — functions, classes, imports, docstrings
- 🔗 **Dependency & call graphs** — powered by NetworkX + pyan3
- 📊 **Cyclomatic complexity** — radon-based, per function, flagged above threshold
- 🧭 **Topological reading order** — tells new developers where to start
- 🤖 **AI-powered Q&A** — NVIDIA NIM, grounded in the graph (no RAG/vectors)
- 🖥️ **Streamlit UI** — interactive pyvis graph, complexity table, query tab

## Quick Start

```bash
# 1. Clone
git clone https://github.com/Hemanth0411/vishleshana.git
cd vishleshana

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure
cp .env.example .env
# Edit .env — add your NIM_API_KEY

# 4. Run
streamlit run main.py
```
